About This Project

This project focuses on website accessibility auditing. It aims to identify barriers that may prevent people, including people with disabilities, from accessing and using digital services effectively.

Project Objectives

Identify Barriers

Find potential accessibility problems in website structure, navigation, text, and interactive elements.

Document Evidence

Record audit findings and supporting evidence so issues can be understood and investigated.

Recommend Solutions

Suggest practical improvements that help make websites easier to use for more people.

Accessibility Audit Findings

The following are example findings for an accessibility audit. Replace them with your verified findings and evidence from the website you tested.

High Priority

1. Keyboard Navigation

Potential issue: Some interactive elements may not be accessible using only a keyboard.

Recommended solution: Ensure interactive elements can receive keyboard focus and be operated using the keyboard.

High Priority

2. Form Labels

Potential issue: Input fields may lack clear, programmatically associated labels.

Recommended solution: Add descriptive labels associated with their corresponding form controls.

High Priority

3. Image Alternatives

Potential issue: Meaningful images may not have appropriate alternative text.

Recommended solution: Add concise, meaningful alt text to informative images and appropriate alternatives to image links.

Medium Priority

4. Colour Contrast

Potential issue: Some text may not have sufficient contrast against its background.

Recommended solution: Check colour contrast and adjust text or background colours where necessary.

Medium Priority

5. Heading Structure

Potential issue: Headings may not follow a logical hierarchy.

Recommended solution: Organise headings to communicate the page structure clearly to users and assistive technologies.

Accessibility Testing Methods

Automated Testing

Use tools such as Lighthouse to identify potential accessibility issues and review the reported results.

Keyboard Testing

Navigate the website using Tab, Shift + Tab, Enter, and Space wherever appropriate.

Manual Review

Check headings, form labels, image alternatives, focus indicators, and text contrast.

Recommendations

  1. Fix verified high-priority accessibility issues first.
  2. Ensure important functions work with keyboard navigation.
  3. Provide meaningful labels and image alternatives.
  4. Review colour contrast and page heading structure.
  5. Retest the website after implementing improvements.
  6. Document evidence, fixes, and remaining issues.

Accessibility Standards

This project uses the Web Content Accessibility Guidelines (WCAG) as a reference for accessibility evaluation. Findings should be checked against the applicable WCAG criteria before being reported as confirmed violations.
